Actúa como desarrollador frontend especializado en sitios web estáticos con HTML5 y CSS3.

Necesito adaptar la plantilla actual del sitio web de PLADEMO usando únicamente HTML y CSS. No usar React, Vite, JSX, Angular, Vue, Node.js ni estructura de componentes. El sitio debe ser estático, limpio, organizado y fácil de editar.

El objetivo es construir el sitio con base en el Home ya trabajado de PLADEMO, respetando su identidad visual industrial, moderna y comercial.

1. productos.html
   Debe mostrar los productos vigentes de PLADEMO como catálogo técnico, no como tienda en línea.

Productos visibles:

- Rollo Polietileno calibre 600
- Bolsas para basura “Es-Rollo”
- Bolsas Hoteleras
- Soluciones de empaque a medida

No mostrar estos productos:

- Bolsa tipo camiseta
- Bolsa para hielo
- Película termoencogible
- Cubre trajes

La página de productos debe incluir:

- Banner superior
- Introducción breve
- Grid de productos
- Imagen de cada producto
- Descripción corta
- Usos principales
- Botón “Solicitar cotización”
- CTA final de contacto

2. mercados.html
   Debe mostrar:

- Industria General
- Industria Química
- Comercio y Retail
- Hotelería
- Construcción
- Agricultura

3. nosotros.html
   Debe presentar la empresa, experiencia, capacidad industrial y compromiso ambiental.

4. contacto.html
   Debe incluir:

- Datos de contacto
- Formulario visual
- WhatsApp
- Ubicación
- Sección “Trabaja con nosotros” dentro de la misma página, no como página independiente.

Tipografías:

- Lexend para títulos principales.
- Gilroy para textos secundarios, descripciones, navegación y botones.
- Si Gilroy no se puede cargar, usar una sans serif similar.

Paleta de colores:

- Azul claro: #bbdaea
- Azul marino: #0f2d56
- Verde principal: #007d32
- Verde oscuro: #1a3b23
- Verde claro: #c0f1be
- Blanco: #ffffff
- Gris secundario: #5f6b76

Estilo visual:

- Industrial
- Moderno
- Limpio
- Comercial
- Profesional
- Enfocado en cotización, no en venta directa

Requisitos técnicos:

- Usar HTML semántico.
- Usar CSS limpio y ordenado.
- Definir colores como variables CSS en variables.css.
- Crear responsive.css para adaptación móvil.
- No poner todos los estilos inline.
- No usar JavaScript si no es necesario.
- El menú móvil puede resolverse con CSS si es posible.
- Optimizar imágenes en formato WebP.
- No usar capturas de pantalla como imágenes finales.
- No incluir imágenes antiguas de productos retirados en la versión final.

El resultado debe ser un sitio estático profesional de PLADEMO construido solamente con HTML y CSS, manteniendo la estructura visual del Home ya diseñado y preparado para continuar con la página de Productos.
